Kramerius IIIF gateway

IIIF Presentation API 3.0 manifests for the digital libraries in the Kramerius registry.

Endpoints

RouteWhat it returns
/{library}/{pid}The manifest or collection for one object.
/{library}/{pid}/dimensionsHow much of this document's page sizes are cached.
/resolve?link=…Redirects from a Digital Library URL to its manifest.
/librariesWhich libraries resolve, to which adapter, and how the sync is doing.
/health, /versionOperational.

Example

/mzk/uuid:71d66fe0-d986-11e2-9923-005056827e52

Manifests are served with Access-Control-Allow-Origin: *, so they load directly in Mirador, the Universal Viewer and Clover.

A response carrying X-IIIF-Dimensions: partial is provisional: some canvases still declare a nominal size while the real ones are being measured. It is not cached, and a later request returns the complete manifest.
